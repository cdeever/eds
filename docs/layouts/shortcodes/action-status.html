{{- /* Status of one incident action or follow-up, as a colored badge. Shares its colors with inc-status. red: Open orange: In Progress (actions), Scheduled (follow-ups) green: Done gray: Declined - deliberately not done, with the reason written down Usage: {{< action-status "In Progress" >}} */ -}} {{- $st := .Get 0 -}} {{- $colors := dict "Open" "red" "In Progress" "orange" "Scheduled" "orange" "Done" "green" "Declined" "grey" -}} {{- $c := index $colors $st -}} {{- if not $c -}} {{- errorf "action-status: unknown status %q in %s - use Open, In Progress, Scheduled, Done or Declined" $st .Position -}} {{- end -}} {{ $st }}
